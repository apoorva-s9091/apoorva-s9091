## Featured Projects

### 🛡️ AetherCept — DDoS & Bot Detection System
ML-based network security system using Isolation Forest for real-time anomaly detection. Built with a Flask API, hosted on our own server, and tested with a Selenium-based bot simulator.
[→ View Repo](https://github.com/anantdub3y/DDoS-Protection-System)

### 🧠 SynapseOnboard — Adaptive Onboarding Engine
8-layer ML pipeline with BERT-based NER, semantic similarity, ChromaDB RAG, and DeepSeek-R1 via Ollama for reasoning and quiz generation.

### 🌿 Smart Crop Disease Detector
Staged architecture from HOG + XGBoost to fine-tuned EfficientNet on PlantVillage dataset (54K images, 38 classes).
